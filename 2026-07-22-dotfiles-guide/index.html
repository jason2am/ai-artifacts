🔗Stow 運作原理

.stowrc · setup.sh

GNU Stow 原本是套件管理工具，這裡拿來當「symlink farm 管理器」。它會把 repo 裡的目錄結構，鏡射成家目錄裡的符號連結。

# .stowrc — 預先設定 stow 的行為
--target=~/.config       # 連結目標是 ~/.config（不用每次手打）
--ignore=.stowrc         # 不要連結 .stowrc 本身
--ignore=DS_Store        # 忽略 macOS 的 .DS_Store
# setup.sh — 就是一行
stow .

執行 stow . 後，例如 tmux/tmux.conf 會變成 ~/.config/tmux/tmux.conf 的來源。修改 repo 裡的檔案 = 直接修改生效中的設定（因為是連結，不是複製）。

💡 為什麼用 Stow？
設定檔留在 git repo 內、集中管理、可追蹤歷史；同時系統仍然在 ~/.config 找得到它們。換新電腦時只要 git clone + stow . 就還原整個環境。
🔎 例外：Zsh
zshrc/.zshrc 例外——它被連到 ~/.zshrc 而不是 ~/.config/，因為 zsh 預設在家目錄讀設定。

自訂函式（導航神器）

🚀Starship — starship/starship.toml

跨 shell 的提示字元引擎

採用「極簡左側 + 資訊全塞右側」的佈局，配色是完整的 Catppuccin Mocha 調色盤。

add_newline = false
format = """$directory$character"""       # 左側只顯示目錄 + 提示符號
right_format = """$all"""                  # git / 語言 / 雲端等全部靠右
palette = "catppuccin_mocha"
command_timeout = 1000
  • character：成功時綠色 ➜，Vi 一般模式顯示 [N] >>>。
  • aws：顯示 profile 與 region（藍色粗體）。
  • golang：只顯示一個 Go 圖示 （青色）。
  • kubernetes / docker_context：預設停用（disabled = true）。
  • directory.substitutions：把長路徑縮寫成短別名。

📜Atuin — atuin/config.toml

用 SQLite 取代 shell 歷史，支援模糊搜尋與跨機同步

Atuin 接管 Ctrl+R 的歷史搜尋，把所有指令存進資料庫並可加密同步。這個設定檔幾乎全用預設值（註解狀態），只覆寫了三項：

設定值意義
stylecompact精簡 UI（不佔滿全螢幕）
enter_accepttrue按 Enter 直接執行選中指令（Tab 則回到編輯）
[sync] recordstrue啟用 sync v2 同步協定
🔐 內建安全防護
secrets_filter 預設開啟：AWS key、GitHub PAT、Slack token、Stripe key 等會被自動排除，不寫入歷史。

📺Television — television/

config.toml + cable/*.toml（80+ 個「頻道」）

Television（tv）是一個超快的通用模糊搜尋器。它的核心概念是「頻道 (channel)」——每個頻道定義「資料來源指令 + 預覽方式」。這套設定內建了 80 幾個頻道，涵蓋 git、docker、k8s、aws、npm、cargo 等。

主設定 config.toml

default_channel = "files"
theme = "catppuccin"
[ui] orientation = "landscape"       # 橫向佈局
[ui.preview_panel] size = 65             # 預覽面板佔 65%

Shell 整合：智慧觸發

最強大的地方是 channel_triggers——依你輸入的指令，Ctrl+T 會自動叫出對的頻道：

你輸入…按 Ctrl+T 觸發
git checkout / git branchgit-branch 頻道
cd / ls / zdirs 頻道
docker rundocker-images 頻道
nvim / code / git clonegit-repos 頻道
其他所有指令files（fallback）

Ctrl+R 則觸發 command_history 頻道。頻道檔案範例（channels.toml）用 tv list-channels 當來源，讓你能用 tv 來搜尋 tv 的頻道。

🪟AeroSpace — aerospace/aerospace.toml

macOS 平鋪式視窗管理器（i3 風格）

AeroSpace 用「虛擬工作區 + 平鋪」取代 macOS 原生的 Spaces。所有操作走 Alt（Option）鍵。

視窗焦點與移動

按鍵行為
Alt+h/j/k/l移動焦點（左/下/上/右）
Alt+Shift+h/j/k/l移動視窗
Alt+1..4切換到工作區 1–4
Alt+Shift+1..4把視窗丟到工作區 1–4
Alt+Tab在前後兩個工作區間切換
Alt+/ / Alt+,切換平鋪 / accordion 佈局
Alt+Shift+-/=縮小 / 放大視窗

模式 (binding modes)

  • Alt+Shift+; → service 模式：esc 重載設定、r 重置佈局、backspace 關掉其他所有視窗。
  • Alt+Shift+Enter → apps 模式：快速開 App。

App 快速啟動 & 浮動規則

直接 Alt+字母開 App：o=Obsidian、s=Slack、w=WezTerm、z=Zen、e=Final Cut、b=Brain.fm。此外 Finder、Safari、Telegram、Discord、Mail 等會被強制設為浮動視窗（不參與平鋪）。

與 SketchyBar 整合

after-startup-command = ['exec-and-forget sketchybar']
exec-on-workspace-change = ['/bin/bash', '-c',
  'sketchybar --trigger aerospace_workspace_change ...']

每次切換工作區都會通知 SketchyBar 更新高亮。工作區固定綁螢幕：1→內建螢幕、2→DELL U 系列、3→DELL S 系列。間距（gaps）在主螢幕特別大（外邊距 350px），營造置中視窗效果。

🎹Karabiner-Elements — karabiner/karabiner.json

底層鍵位重映射引擎

Karabiner 在最底層改寫鍵盤事件。這裡最實用的兩條規則，讓你不用移到方向鍵區就能用箭頭：

組合對應
右Cmd+h/j/k/l← ↓ ↑ →（方向鍵）

⚠️ 弱 MAC 演算法
設定中有 MACs hmac-md5,hmac-sha1——這兩者已不安全，通常只為相容老舊裝置保留。連接現代伺服器建議移除此行。
