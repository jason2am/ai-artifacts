🎯 1. Television 是什麼✓已學會

📺
television (指令 tv)
用 Rust 寫的通用 fuzzy finder TUI

可以把它想成「會分頻道的 fzf」。fzf 只是吃一段 stdin 然後讓你模糊搜尋； television 多了 channel（頻道） 的概念 —— 每個 channel 是一份設定， 定義「資料從哪來（source）、怎麼預覽（preview）、按鍵做什麼動作（actions）」。

所以同一個工具，可以是檔案搜尋器、git 分支切換器、Docker 容器管理器、process 管理器…… 切換 channel 就切換用途。

核心心智模型

  • Source — 一個 shell 指令，產生候選清單（例如 fd -t f 列檔案）。
  • Filter — 你打字，television 即時模糊比對。
  • Preview — 對目前選取項目跑一個指令顯示在右邊（例如 bat 看檔案內容）。
  • Action — 按特定鍵對選取項目執行指令（例如 Enter 用 nvim 開啟）。
一句話 television = 可重複使用的「搜尋 → 預覽 → 動作」管線，每個用途存成一個 channel。

3.3 全域快捷鍵 [keybindings]

這些鍵在「任何 channel」都生效（channel 可再覆寫）。完整速查見第 9 節。重點分群：

  • 離開：esc / ctrl-c → quit
  • 移動：上下方向鍵，或 vim/emacs 風格 ctrl-n/p、ctrl-j/k
  • 多選：tab 選取並往下、enter 確認
  • 預覽捲動：ctrl-d / ctrl-u 半頁捲動、ctrl-f 切換多個 preview
  • 面板開關：ctrl-r 遙控器（換 channel）、ctrl-o 預覽、ctrl-t 版面、F9 說明

3.4 Shell 整合 [shell_integration]

這是讓 tv 能在你打指令時自動跳出對應 channel 的關鍵設定，獨立講在第 8 節。

🧬 4. Channel 結構解剖✓已學會

每個 cable/*.toml 都是同一套結構。用最簡單的 files.toml 當範本：

[metadata]
name = "files"
description = "A channel to select files and directories"
requirements = ["fd", "bat"]        # 需要安裝的外部工具

[source]                                  # ← 候選清單從哪來
command = ["fd -t f", "fd -t f -H", "fd -t f -H -I"]  # 多來源可用 Ctrl-S 循環切換

[preview]                                 # ← 選取項目怎麼預覽
command = "bat -n --color=always '{}'"      # {} = 目前選取的那一行
env = { BAT_THEME = "ansi" }

[keybindings]                             # ← 此 channel 專屬按鍵
shortcut = "f1"                        # 從別的 channel 按 F1 直接跳來
enter = "actions:edit"               # Enter 觸發下面定義的 edit action
ctrl-up = "actions:goto_parent_dir"

[actions.edit]                            # ← 自訂動作
description = "用預設編輯器開啟選取項目"
command = "nvim '{}'"
shell = "nu"                          # 用哪個 shell 跑這指令
mode = "execute"                       # execute = 跑完離開；fork = 跑完留在 tv

[ui.preview_panel]
hidden = true                         # 此 channel 覆寫全域：預設不顯示預覽

各區塊速記

區塊角色關鍵欄位
[metadata]名稱、描述、依賴工具name · description · requirements
[source]產生候選清單的指令command · display · output · ansi
[preview]預覽選取項目command · env · offset
[keybindings]按鍵 → 動作對應shortcut · enter · ctrl-*
[actions.NAME]可被按鍵觸發的動作command · mode · shell
[ui]覆寫該 channel 的版面layout · preview_panel
source vs output vs display command 是原始輸出；display 改「顯示給你看的樣子」； output 改「實際傳給 action 的值」。三者分離 → 可以顯示漂亮、傳值乾淨。

mode：execute vs fork

execute跑完指令後關閉 tv（例如用 nvim 開檔案）
fork跑完後留在 tv 繼續操作（例如 git add 後繼續選下一個）

🔧 5. Template 語法（最重要的觀念）✓已學會

channel 裡到處出現的 {...} 是 television 的 template placeholder。 看懂它，所有 channel 你都讀得懂。基本款 {} = 目前選取的整行文字。

常用 transformer（用 | 串接，像 shell pipe）

語法作用範例
{}整行原始字串選到的檔名/文字
{split:X:N}用 X 切開，取第 N 段（0 起算）{split: :1} 取第二欄
{split:X:N..M}取一段範圍（slice）{split:\::..2} 取前兩段
{strip_ansi}去掉 ANSI 顏色碼source 有 --color=always 時必用
{join:X}把多段用 X 接回去{...|join: } 用空格接回

實戰：讀懂 git-log 的 placeholder

git log 那行長這樣（含顏色與圖形）：* a1b2c3d - (HEAD) 修個 bug (2 hours ago) <jason>

output = "{strip_ansi|split: :1}"

拆解這條管線：

  • strip_ansi → 先把顏色碼拿掉
  • split: :1 → 用空格切開，取第 1 段（0 是 *，1 就是 commit hash a1b2c3d）

所以不管那行顯示多花俏，傳給 git show、git cherry-pick 的永遠是乾淨的 commit hash。

另一個：todo-comments 帶行號跳轉

ripgrep 輸出格式是 檔案:行號:內容，channel 這樣處理：

command = "${EDITOR:-vim} '+{strip_ansi|split:\\::1}' '{strip_ansi|split:\\::0}'"
                          ↑ 第1段=行號         ↑ 第0段=檔名

split:\::0 用冒號切、取檔名；split:\::1 取行號。 組成 vim +行號 檔名 → 直接跳到那一行。（\: 是跳脫冒號當分隔符。）

💡 讀 channel 的訣竅　看到一長串 {strip_ansi|split:...|join:...} 不要怕， 從左到右當 pipe 唸：去色 → 切欄 → 取第幾段 → 接回去。本質就是在「整理 source 的某一欄」當參數。

🔬 7. 重點 Channel 拆解✓已學會

挑幾個你最常用、或設計上有亮點的 channel 詳細看。

📁 files — 預設頻道（F1）

sourcefd -t f →（Ctrl-S）→ 含隱藏 → 含被 gitignore 的
previewbat 帶行號與顏色，但 hidden = true 預設關閉預覽（要看按 Ctrl-O）
Enter用 nvim 開啟
Ctrl-↑跳到上層目錄重開（tv files ..）

📂 dirs — 目錄（F2）

source 是 fd -t d，預覽用 eza -la 列出目錄內容。action cd 會在選取目錄開一個新 shell。

🌿 git-branch — 分支切換

command = "git --no-pager branch --all --format=\"%(refname:short)\""
output  = "{split: :0}"     # 取分支名第一欄

一個 channel 把整套分支操作收進按鍵：

Entercheckout 切換分支
Ctrl-D刪除分支
Ctrl-Mmerge 進當前分支
Ctrl-Rrebase 到選取分支

🌿 git-log — 提交歷史

source 用花俏的 --graph --pretty --color=always，靠 output = "{strip_ansi|split: :1}" 萃取 hash。no_sort + frecency = false 保留 git 原始時間順序。動作：Ctrl-Y cherry-pick、Ctrl-R revert、Ctrl-O checkout。

🌿 git-diff — 暫存區工作流（portrait 版面）

覆寫了 [ui] layout = "portrait"（直向，預覽在下方更適合看 diff）。動作 Ctrl-S stage、Ctrl-R restore 都用 mode = "fork"，stage 完留在 tv 繼續處理其他檔。

🖥️ sesh — session 管理（亮點）

command = ["sesh list --icons", "sesh list -t --icons", "sesh list -c --icons",
           "sesh list -z --icons", "fd -H -d 2 -t d -E .Trash . ~"]
output = "{strip_ansi|split: :1..|join: }"   # 去掉開頭 icon，留 session 名

整合 tmux session、zoxide 目錄、設定路徑於一處。Enter connect 連線，Ctrl-D 砍掉 session 並 reload 清單。split: :1..|join: 是把第一個 icon 欄丟掉、其餘用空格接回（處理含空白的名稱）。

🔍 text — 全文搜尋並跳行

用 rg 搜所有檔案內容，offset 讓預覽自動捲到命中行，Enter 用 $EDITOR +行號 開檔跳到該行。todo-comments 是它的近親，只是搜尋條件鎖定 TODO/FIXME/HACK/XXX/BUG/WARN。

📺 channels — 找頻道的頻道

command = "tv list-channels"
[actions.zap] command = "tv '{}'"   # Enter 直接切換到選取的 channel

🐚 8. Shell 整合（殺手級功能）✓已學會

這讓 tv 變成你 shell 的智慧補全。在終端機打到一半按 Ctrl-T， television 會依你打的指令猜你要找什麼，跳出對應 channel。

運作流程

1️⃣ 你輸入

例如在 prompt 打 git checkout

2️⃣ 按 Ctrl-T

觸發 smart_autocomplete

3️⃣ 比對 trigger

「git checkout」對應到 git-branch

4️⃣ 跳出 channel

選分支 → 名稱自動填回指令列

channel_triggers 對應表（你設定的）

觸發 channel當你打這些指令時
aliasalias · unalias
envexport · unset
dirscd · ls · rmdir · z
filescat · vim · bat · cp · mv · rm · tar · chmod …等檔案操作
git-diffgit add · git restore
git-branchgit checkout · git branch · git merge · git rebase · git pull/push
git-loggit log · git show
docker-imagesdocker run
git-reposnvim · code · hx · git clone

兩個觸發鍵

Ctrl-Tsmart_autocomplete — 依目前指令猜 channel
Ctrl-Rcommand_history — 模糊搜尋 shell 歷史指令
fallback_channel = "files" 如果你打的指令沒對到任何 trigger，按 Ctrl-T 就退回 files channel。
⚠️ 注意　shell 整合需要在你的 .zshrc 安裝 hook（tv init zsh）。 這份設定只定義「觸發規則」，實際綁定要 shell 端啟用才會生效。

新增一個自己的 channel

在 cable/ 建一個 my-thing.toml，最小可用範本：

[metadata]
name = "my-thing"
description = "我的自訂頻道"

[source]
command = "some-command-that-lists-things"

[preview]
command = "echo '{}'"

[keybindings]
enter = "actions:do-it"

[actions.do-it]
command = "echo '你選了 {}'"
mode = "execute"

存檔後 tv my-thing 立刻可用，無需重啟。
