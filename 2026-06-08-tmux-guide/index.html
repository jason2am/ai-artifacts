安裝 & 初始化

這份設定使用 TPM（Tmux Plugin Manager） 管理所有插件。在套用設定前需要先安裝 TPM。

步驟 1 — 安裝 TPM

git clone https://github.com/tmux-plugins/tpm ~/.tmux/plugins/tpm

步驟 2 — 套用 dotfiles（personal）

⚠️
此 repo（oss/dotfiles）為版本控制參考用，不要直接 stow 此目錄。本機設定在 ~/code/personal/dotfiles，執行以下指令套用： 
cd ~/code/personal/dotfiles && ./setup.sh

步驟 3 — 安裝所有插件

啟動 tmux 後，按下：

Ctrl+A 然後 I（大寫）

TPM 會自動下載並安裝所有在 tmux.conf 中宣告的插件。

步驟 4 — 重新載入設定

tmux source-file ~/.config/tmux/tmux.conf

或在 tmux 內按：Ctrl+A R

設定檔結構

~/.config/tmux/
├── tmux.conf          # 主設定檔（插件、主題、選項）
├── tmux.reset.conf    # 自訂快捷鍵（由 tmux.conf source）
└── scripts/
    └── cal.sh         # 行事曆整合腳本（目前已停用）

tmux.conf 第一行即 source-file ~/.config/tmux/tmux.reset.conf，確保自訂按鍵優先載入，再由插件補充。

基本選項

設定值效果
base-index 1 視窗從 1 開始編號，符合鍵盤左起習慣
detach-on-destroy off 關閉 session 時不退出 tmux，自動切換到其他 session
escape-time 0 消除 Esc 鍵延遲，Neovim 等編輯器反應更快
history-limit 1,000,000 每個 pane 保留 100 萬行歷史，可往上滾動超長輸出
renumber-windows on 關閉視窗後自動重新編號，保持連續
set-clipboard on 複製時同步到系統剪貼簿
status-position top Status bar 顯示在上方（macOS 風格）
mode-keys vi Copy mode 使用 Vim 按鍵（j/k 移動、v 選取）

Prefix 鍵

tmux 的所有操作都需要先按 Prefix 再按指令鍵。

set -g prefix ^A   # 改為 Ctrl+A（預設是 Ctrl+B）
💡
為什麼用 Ctrl+A？
Ctrl+A 是 GNU Screen 的傳統 prefix，小指不用跨越到 B，且與許多開發者的肌肉記憶一致。
狀況按法
執行 tmux 指令Ctrl+A 放開 → 按指令鍵
在 Vim 中使用 Ctrl+A（數字遞增）按兩次 Ctrl+A

終端機設定

set-option -g default-terminal 'screen-256color'
set-option -g terminal-overrides ',xterm-256color:RGB'
set -g default-terminal "${TERM}"
效果
支援 24-bit 真彩色（Neovim 主題色彩正確顯示）
繼承外部終端機（Ghostty）的 TERM 變數
確保 256 色相容性

Pane 邊框

set -g pane-active-border-style 'fg=magenta,bg=default'
set -g pane-border-style        'fg=brightblack,bg=default'
邊框顏色說明
目前聚焦的 pane■ Magenta（紫紅）清楚識別目前操作的 pane
未聚焦的 pane■ Bright Black（深灰）低調，不搶視覺焦點

快捷鍵 — Session 管理

所有快捷鍵均需先按 Ctrl+A 作為 Prefix。

按鍵指令效果
^A ^D detach 離開 tmux 回到 shell（session 在背景繼續運行）
^A S choose-session 開啟 session 選擇清單
^A o tmux-sessionx 開啟 fzf session 管理器（可建立/切換/預覽）
^A $ rename-session 重新命名目前 session
^A : → kill-session kill-session 關閉目前 session（無獨立快捷鍵，需透過 command mode 輸入）
^A ^X lock-server 鎖定 tmux server
^A * list-clients 列出所有連線的 client

快捷鍵 — Window 管理

按鍵效果
^A ^C 在 $HOME 開新視窗
^A H 切換到上一個視窗（previous-window）
^A L 切換到下一個視窗（next-window）
^A ^A 切換到上次使用的視窗（last-window）
^A ^W 或 w 列出所有視窗
^A " choose-window 選擇器
^A r 重新命名目前視窗
^A R 重新載入 tmux.conf

快捷鍵 — Pane 管理

按鍵效果
^A s 水平分割（向下），繼承目前路徑
^A v 垂直分割（向右），繼承目前路徑
^A | 垂直分割（預設路徑）
^A c 關閉目前 pane（kill-pane）
^A x 與下一個 pane 交換位置（swap-pane -D）
^A z Zoom / 全螢幕切換目前 pane
^A P 切換 pane border status（顯示/隱藏邊框標題）
^A p 開啟 tmux-floax 浮動 pane
^A K 清空目前 pane（傳送 clear + Enter）
^A *（pane） 切換 synchronize-panes（同步輸入到所有 pane）

快捷鍵 — Pane 導覽

使用 Vim 方向鍵在 pane 之間移動：

按鍵移動方向
^A h← 左
^A j↓ 下
^A k↑ 上
^A l→ 右（同 refresh-client）

另外：

按鍵效果
^A ^L 或 l重新整理 client 畫面
^A :開啟 tmux 指令輸入模式

快捷鍵 — Pane 調整大小

這些按鍵支援 重複按住（-r 旗標），不需要每次都重按 Prefix。

按鍵效果幅度
^A ,縮小寬度（向左）20 格
^A .增加寬度（向右）20 格
^A -縮小高度（向下）7 行
^A =增加高度（向上）7 行

快捷鍵 — Copy Mode（Vi 模式）

setw -g mode-keys vi
bind-key -T copy-mode-vi v send-keys -X begin-selection
按鍵效果
^A [ 進入 Copy Mode
j / k 上下捲動（Copy Mode 內）
/ 向下搜尋
? 向上搜尋
v 開始選取（begin-selection）
y 複製選取內容（tmux-yank 同步至系統剪貼簿）
q 或 Esc 離開 Copy Mode

tmux-floax — 浮動 Pane

按一個鍵就能召喚/收起一個浮動的終端機 pane，不中斷目前工作。

set -g @floax-width         '80%'
set -g @floax-height        '80%'
set -g @floax-border-color  'magenta'
set -g @floax-text-color    'blue'
set -g @floax-bind          'p'
set -g @floax-change-path   'true'
設定值效果
width / height80%浮動視窗佔螢幕 80%，視覺上夠大不感到擁擠
border-colormagenta紫紅色邊框，易於識別這是浮動 pane
text-colorblue浮動 pane 內文字顏色
bindp觸發鍵：^A p
change-pathtrue自動切換到呼叫時所在的工作目錄

使用方式

操作按鍵
開啟浮動 pane^A p
收起浮動 pane^A p（再按一次）

tmux-sessionx — Session 管理器

整合 zoxide 的強化 session 管理器，可預覽、切換、建立 session。

set -g @sessionx-bind                    'o'
set -g @sessionx-auto-accept             'off'
set -g @sessionx-custom-paths            '/Users/omerxx/dotfiles'
set -g @sessionx-x-path                  '~/dotfiles'
set -g @sessionx-window-height           '85%'
set -g @sessionx-window-width            '75%'
set -g @sessionx-zoxide-mode             'on'
set -g @sessionx-custom-paths-subdirectories 'false'
set -g @sessionx-filter-current          'false'
set -g @sessionx-bind-zo-new-window       'ctrl-y'
設定效果
bind = o^A o 開啟 sessionx 面板
auto-accept = off選取後不自動確認，需按 Enter
window-height/width面板大小 85% × 75%
zoxide-mode = on整合 zoxide 最近目錄，可直接用路徑建立 session
filter-current = false清單中顯示目前 session（不過濾）
bind-zo-new-window = ctrl-y在 sessionx 面板內，Ctrl+Y 以 zoxide 路徑開新視窗

使用方式

操作按鍵
開啟 sessionx^A o
輸入搜尋（session 名稱或 zoxide 路徑）直接打字
切換到選取的 sessionEnter
用 zoxide 路徑開新視窗Ctrl+Y（在面板內）
取消Esc

tmux-resurrect + tmux-continuum — Session 持久化

set -g @continuum-restore       'on'
set -g @resurrect-strategy-nvim 'session'
功能說明
自動儲存 tmux-continuum 每 15 分鐘自動儲存所有 session、window、pane 的狀態
自動還原 continuum-restore = on：tmux 啟動時自動還原上次的環境
Neovim 還原 resurrect-strategy-nvim = session：還原時重新開啟 Neovim 並載入上次的 session 檔

手動操作

操作按鍵
手動儲存^A Ctrl+S
手動還原^A Ctrl+R

catppuccin-tmux — 主題設定

使用 Catppuccin Mocha 配色，搭配自訂 separator 與 status bar 模組。

# Window tab 樣式
set -g @catppuccin_window_left_separator   ""
set -g @catppuccin_window_right_separator  " "
set -g @catppuccin_window_middle_separator " █"
set -g @catppuccin_window_number_position  "right"

# 非當前視窗
set -g @catppuccin_window_default_fill "number"
set -g @catppuccin_window_default_text "#W"

# 當前視窗（含 zoom 指示）
set -g @catppuccin_window_current_fill "number"
set -g @catppuccin_window_current_text "#W#{?window_zoomed_flag,(),}"

# Status bar 模組
set -g @catppuccin_status_modules_right   "directory"
set -g @catppuccin_status_modules_left    "session"
set -g @catppuccin_status_left_separator  " "
set -g @catppuccin_status_right_separator " "
set -g @catppuccin_status_fill            "icon"
set -g @catppuccin_directory_text         "#{b:pane_current_path}"

# 停用中的模組（取消註解可啟用）
# set -g @catppuccin_status_modules_right "directory date_time"
# set -g @catppuccin_meetings_text "#($HOME/.config/tmux/scripts/cal.sh)"
# set -g @catppuccin_date_time_text "%H:%M"

tmux-thumbs — Hint 模式複製

類似 Vimium 的操作：掃描畫面上所有可複製的文字（路徑、hash、URL、IP），每個標上一個字母 hint，按下字母即複製。

使用方式

操作按鍵
觸發 thumbs 模式^A Space（預設）
按下 hint 字母對應文字自動複製到剪貼簿
大寫字母複製並同時貼上

tmux-fzf — fzf 全功能管理器

用 fzf 互動式管理 session、window、pane、keybinding、clipboard 歷史，功能最完整。與 tmux-sessionx 的差別：sessionx 專注 session 切換，tmux-fzf 涵蓋所有資源類型。

觸發方式

按鍵效果
^A F開啟 tmux-fzf 主選單（大寫 F）

主選單選項

選項效果
Sessions切換、新建、重命名、刪除 session
Windows切換、新建、重命名、關閉視窗
Panes切換、交換、分離 pane
Key Bindings搜尋所有快捷鍵並直接執行
Clipboard瀏覽並貼上 tmux buffer 歷史
Processes搜尋程序並傳送 signal
💡
tmux-fzf vs tmux-sessionx
平時切換 session 用 ^A o（sessionx，整合 zoxide，速度快）；需要管理 window/pane/keybind 時用 ^A F（tmux-fzf，功能全）。
